# Bento Box Grid

## Best for
General users who need to scan several ideas quickly.

## Core idea
Organize content into modular cards that feel visual, structured, and easy to compare.

## Above-the-fold layout
- Bold headline
- Grid of feature cards
- One larger feature card for the main idea
- Smaller supporting cards for secondary points

## Visual hierarchy notes
- Vary card size to show importance.
- Keep each card focused on one idea.
- Use icons, numbers, or short labels to improve scanning.

## Works well for
Feature pages, product explainers, dashboards, learning guides, and modern SaaS pages.
